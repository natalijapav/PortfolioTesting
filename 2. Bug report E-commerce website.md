# 🐞 Bug Report: "Load More" List Resets After Returning from Product Detail Page

---

### 🧾 Summary  
When navigating back from a product detail page on the **“Haljine, kombinezoni”** category, the product list resets to a partially loaded state instead of preserving the user’s previous scroll and loaded items.

---

### 📝 Description  
After using the **Load More** button multiple times (e.g., loading *400 of 831 products*), selecting a product to view its details, and then returning to the product listing, the list resets.  
Instead of keeping all previously loaded items, it shows only part of them (e.g., *200 of 831 products*).  

This forces the user to repeatedly click **Load More** to return to the previous position — causing frustration and disrupting the browsing flow.

---

### ⚙️ Environment  
- **Platform:** Desktop  
- **OS:** Windows 10  
- **Browser:** Chrome Version 136  

---

### 🧭 Steps to Reproduce
1. Open **website1.com**  
2. Go to **Haljine → Vidi sve**  
3. Scroll down and click **Load More** several times (until ~400 products are displayed)  
4. Click on any product to open its **detail page**  
5. Use the browser’s **Back** button to return to the listing page  

---

### ✅ Expected Result  
User should return to the **exact same scroll position** and see all **previously loaded products** (e.g., 400/831).  

---

### ❌ Actual Result  
The page resets to a **partially loaded state** (e.g., 200/831).  
User must click **Load More** again to reach the same position.

---

### 🔺 Severity: Medium  
### 🔹 Priority: Medium  

---

### 💡 Suggestion  
Implement caching or state persistence for the product list view, ensuring that the previously loaded data and scroll position are retained when returning from a product detail page.
